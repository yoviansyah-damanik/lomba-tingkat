# Tailwind Styling Skill & Rule

## Ringkasan
Skill dan rule telah ditambahkan agar seluruh styling antarmuka selalu memprioritaskan Tailwind CSS utility classes, bukan script CSS terpisah atau inline style (`style="..."`), kecuali dalam kondisi terpaksa (seperti konfigurasi cetak `@page` atau nilai kalkulasi dinamis runtime).
