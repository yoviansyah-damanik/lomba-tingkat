# Flux Button Skill & Rule

## Ringkasan
Skill dan aturan baru telah ditambahkan agar seluruh elemen tombol, trigger, dan action link selalu menggunakan `<flux:button>`. Jika tombol memiliki ikon, gunakan atribut `icon="..."` (misal `<flux:button icon="check">`) alih-alih menyematkan tag ikon/svg manual di dalam tombol.
